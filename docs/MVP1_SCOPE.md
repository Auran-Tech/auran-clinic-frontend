# MVP 1 Scope

MVP 1 is the responsive production web application for clinic staff.

Included: authentication/session lifecycle, multi-clinic isolation, permission RBAC, clinic settings, patients and duplicate detection, dynamic patient profiles, measurements, live queue/workflow, visits/sessions, clinical documentation, prescriptions, clinical orders/attachments, follow-ups, employees/roles/permissions, basic reports, audit, Arabic/English, RTL/LTR and responsive web.

Excluded: native/mobile app (MVP 2), patient app/portal, appointments, billing/accounting, insurance, pharmacy inventory, external lab/radiology, subscriptions/plans, offline sync, microservices/message broker and customer-specific code.

A module is done only when UI, API, authorization, clinic isolation, validation, error states, audit behavior, tests and responsive behavior are complete.
