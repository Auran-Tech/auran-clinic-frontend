# MVP 1 Delivery Plan

Work is delivered as vertical slices across the backend and React frontend.

## Slice 1 — Patients
- Login/session integration
- Patient list/search
- Duplicate detection
- Create patient
- Patient basic profile
- Update patient
- Tenant isolation and audit tests

## Slice 2 — Patient clinical profile
- Dynamic profile sections/fields
- Allergies, conditions, medications
- Measurements
- Attachments

## Slice 3 — Live Queue
- Check-in
- Workflow states/transitions
- Priority
- Doctor assignment
- Real-time refresh strategy

## Slice 4 — Visits
- Start/reopen/complete visit
- Visit sessions
- Doctor workspace
- Draft/autosave clinical documentation
- Prescription and clinical orders

## Slice 5 — Follow-ups
- Due/upcoming/overdue/completed
- Create/edit/complete/cancel

## Slice 6 — Administration
- Employees
- Roles/permissions
- Clinic settings/configuration

## Slice 7 — Reports/Audit
- MVP operational reports
- Export where required
- Audit search/filter

## Release hardening
- Full Arabic/English and RTL/LTR
- Accessibility
- Responsive regression
- End-to-end tests
- Security review
- Production deployment runbook

Native/mobile clinic app is MVP 2.
